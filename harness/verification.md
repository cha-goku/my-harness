# 검증과 리뷰 (R8)

## 판정 스크립트 검증

규칙마다 "정상 입력 1개(통과해야 함)"와 "위반 입력 1개(걸려야 함)"를 `harness/fixtures/`에 만든다. 전부 기대한 결과가 나오면 통과다.

| 대상 | 픽스처 |
|---|---|
| G1 조건 4개 | 조건마다 정상 1, 위반 1 |
| G2 조건 4개 | 조건마다 정상 1, 위반 1 |
| S5 디자인 규칙 8개 | 규칙마다 정상 1, 위반 1 |
| 서비스 규칙 2개 | 규칙마다 정상 1, 위반 1 (예: 비공개가 아닌 기본값 화면, 검수 없이 "승인됨"으로 가는 전환) |
| S5 프레임 검사 (FRM-0~4) | 위반 입력 10개와 정상 입력 1개(모든 행 체크 + 승인 버튼 활성이면 통과). `fixtures/valid`의 내보내기에 내 자산 등록·운영자 검수 프레임이 들어 있다 |

## 문서 간 일치 검사

스크립트 1개가 `rules.json`과 `design.md`의 숫자 값을 비교한다. 다르면 실패로 처리한다.

## 시범 실행

스킬 라이브러리 화면 묶음 1개로 S1부터 S5까지 끝까지 돌린다.

## 완료 기준

1. 픽스처 테스트가 전부 통과한다.
2. 시범 실행 1회가 S5 위반 0건에 도달하거나, 같은 단계에서 3번 실패한 뒤 사람에게 정상적으로 넘어간다.

## 리뷰

사람 리뷰는 시범 실행이 끝난 뒤 1번 한다.

## 만드는 순서

`CLAUDE.md` 승인 → `rules.json` → 판정 스크립트 → 픽스처 → 에이전트 파일 → 시범 실행
