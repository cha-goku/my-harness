# 게이트 (R5)

모든 조건은 스크립트가 셀 수 있는 형태다. 사람이 승인하는 곳은 G3 한 곳뿐이다. 같은 단계에서 3번 실패하면 자동 반복을 멈추고 사람에게 넘긴다.

## S5에서 세는 디자인 규칙 (`design.md`를 숫자로 바꾼 것)

- 폰트 굵기는 300, 400, 700만 허용
- 모서리는 0, 16, 24, 9999px만 허용 (앱 아이콘만 30% 예외)
- 그림자 0개 (세그먼트 컨트롤의 활성 항목만 예외)
- 버튼 모서리는 모두 9999px
- 글자 간격은 모두 0
- 색은 팔레트 안의 값만 허용
- `accent` 색 사용은 화면당 2곳 이하이고, 버튼 채움에는 0곳
- 간격은 4의 배수, 좌우 여백은 16px

## S5 프레임 검사 (서비스 규칙을 Figma 프레임에서 직접 확인)

설계 문서의 값만 보는 것이 아니라, `design-export.json`의 프레임 노드(`text`, `variant`)를 읽는다.

| 규칙 | 조건 | 규칙 번호 |
|---|---|---|
| 기본 비공개 | 내 자산 등록 프레임에서 선택된 공개 범위 옵션이 정확히 1개이고 그 이름이 "비공개" | FRM-1 |
| 판매 신청은 판매 승인 회원만 | "판매 신청" 옵션이 있는 프레임은 설계에서 seller 전용인 화면 변형뿐 | FRM-2 |
| 승인 버튼은 체크리스트 완료 후 | 체크 안 된 행이 있으면 "승인" 버튼이 비활성 컴포넌트이고, 승인 버튼이 프레임에 있음. 체크리스트 프레임이 없으면 실패 | FRM-3 |
| 체크리스트 8개 | 체크리스트 항목 행이 8개이고 PRD 8개 항목이 모두 있음 | FRM-4 |
| 대응 화면 | 프레임이 설계 화면에 대응하고, 내 자산 등록 설계 화면마다 프레임이 있음 | FRM-0 |

"검수 없이 승인됨으로 가는 전환"은 화면 하나로는 볼 수 없어서 설계 문서의 `transitions`(SVC-3)로만 검사한다.

## 서비스 규칙 위반 조건 (G2와 S5 모두 검사)

`../story-service.md`의 "어기면 안 되는 것"을 위반하면 걸린다.

| 어기면 안 되는 것 | 세는 조건 | 근거 |
|---|---|---|
| 자료는 기본 비공개, 본인이 선택할 때만 공개·판매 신청 | 자산 등록·수정 화면에서 공개 범위의 기본 선택값이 "비공개"인 화면 100%, 다른 옵션이 기본 선택된 화면 0개. "판매 신청" 옵션이 보이는 화면은 판매 승인 회원(seller) 역할로 명시된 화면뿐 | PRD §14, §7-4 |
| 판매 자산은 운영자 검수를 통과해야 하고, 개인정보·기밀·저작권 문제가 없어야 함 | ① 검수 없이 "승인됨"으로 가는 화면 전환 0개 ② 운영자 검수 화면에 판매 기준 체크리스트 8개 항목이 모두 있음 (개인정보와 저작권 항목 포함) ③ 체크리스트를 다 채우기 전까지 승인 버튼이 비활성 | PRD §6-7, §14 |
