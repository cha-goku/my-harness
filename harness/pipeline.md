# 파이프라인 (R3)

`../story-work.md`의 7단계를 5단계로 묶었다. 게이트 G1~G3은 단계 사이에 그대로 둔다.

| 단계 | 묶은 문장 | 입력 | 출력 | 넘어가기 전 게이트 |
|---|---|---|---|---|
| S1 리서치 | 1, 2 | 화면 묶음 이름, 레퍼런스 범위 | 레퍼런스 모음, 분석 내용(반영할 부분) | G1 분석 확인 |
| S2 설계 | 3 | 분석 내용, PRD | 화면 설계 문서 | G2 설계 문서 확인 |
| S3 시안 | 4, 5 | 설계 문서, 레퍼런스 | 키스크린 2~3개 (390×844, Figma) | G3 내부 관계자 컨펌 |
| S4 제작 | 6 | 컨펌된 시안, `design.md` | 토큰, 컴포넌트, 화면 디자인 | 없음 |
| S5 검수 | 7 | 토큰·컴포넌트·화면, `design.md` | 위반 검토 결과 | 위반 0건이면 종료 |

## 되돌아가는 지점

| 상황 | 돌아가는 곳 |
|---|---|
| G1 반려 | S1 재실행 |
| G2 반려 | S2 재실행 |
| G3 반려 | S3로 돌아감 |
| S5에서 위반 발견 | S4로 돌아감 |

같은 단계에서 3번 실패하면 자동 반복을 멈추고 사람에게 넘긴다.

## 두 번째 화면 묶음부터

- S1: 새 묶음의 레퍼런스만 수집한다.
- S2: 그대로 한다 (화면이 다르므로 설계 문서는 새로 필요하다).
- S3: 건너뛴다 (컨셉은 첫 묶음에서 확정됨).
- S4~S5: 그대로 한다.
