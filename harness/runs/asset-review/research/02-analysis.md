# 분석

## 반영할 부분

- [A1] 내 자산 등록 / PRD §6-5 "새 자산 등록·설명 작성": 상단 뒤로가기와 제목·본문 입력 중심의 단일 작성 폼으로 구성하고, 하단에 임시저장(보조)과 저장/등록(주) 버튼을 나란히 둔다. 임시저장은 상태 "임시저장"과 연결된다. 근거: R1
- [A2] 내 자산 등록 / PRD §6-5 "공개 범위 선택": 공개 범위는 라디오 버튼 그룹으로 보여주고 각 옵션 옆에 한 줄 설명을 붙인다. 옵션은 비공개 / 멤버 공개 / 판매 신청 3개이며 기본 선택은 비공개(PRD §14). "판매 신청"은 판매 승인 회원(seller)에게만 보이거나 활성화한다(PRD §7-4). 근거: R3, R4
- [A3] 내 자산 등록 / PRD §6-5 "설명 작성·파일 첨부": 분류·태그처럼 고르는 항목은 칩·태그로, 긴 선택지는 바텀시트 목록으로 나눠 폼이 길어지지 않게 한다. 근거: R2, R4
- [A4] 내 자산 등록 / PRD §6-5 "판매 신청 상태 확인" (제안: 등록 화면을 여러 단계로 나눌지 여부. PRD에 단계 구분은 없음): 폼이 길어지면 진행 표시(2/3 같은 단계 표시)로 나눠 보여줄 수 있다. 근거: R2
- [A5] 내 자산 등록 / PRD §6-5 "내 자산 목록, 판매 신청 상태 확인": 목록의 각 항목 오른쪽에 상태 배지(임시저장 / 검수 대기 / 수정 요청 / 승인됨 / 반려)를 붙이고, 상태별로 배지 색과 글자를 구분한다. 판매 중·판매 중지 상태는 넣지 않는다(Phase 2). 근거: R5, R9, R10
- [A6] 내 자산 등록 / PRD §6-5 "내 자산 목록" (제안: 상태별 탭 필터. PRD에 필터 요구는 없음): 목록 상단에 탭이나 칩으로 상태별 보기를 둔다. 근거: R5
- [A7] 운영자 검수 / PRD §6-7 "검수 대기 목록": 검수 대기 목록도 카드형 항목 + 상태 배지 구조를 그대로 쓰되, 제작자·제출일·자산명을 한눈에 보이게 한다. 근거: R9, R10
- [A8] 운영자 검수 / PRD §6-7 "판매 기준 체크리스트 8개": 8개 기준을 체크박스 목록으로 세로로 나열하고, 상단에 "전체 확인" 행을 둔다. 개인정보·저작권 항목은 필수 표시로 눈에 띄게 한다. 근거: R6, R7
- [A9] 운영자 검수 / PRD §6-7 "승인" (게이트 규칙 G: 체크리스트 완료 전 승인 버튼 비활성): 하단 고정 버튼은 체크리스트를 모두 채우기 전까지 비활성 상태로 두고 채우면 활성으로 바꾼다. 근거: R6, R7
- [A10] 운영자 검수 / PRD §6-7 "체크리스트 항목 설명": 항목마다 펼침(자세히 보기) 영역을 두어 판단 기준을 필요할 때만 볼 수 있게 한다. 근거: R8
- [A11] 운영자 검수 / PRD §6-7 "승인/수정 요청/반려": 최종 결정 버튼은 승인(주) 한 개와 수정 요청·반려(보조) 두 개를 하단에 구분해 배치한다. 근거: R6, R8
- [A12] 운영자 검수 / PRD §6-7 "수정 요청 코멘트 작성, 가격 설정 또는 가격 승인" (제안: 바텀시트로 열기. PRD에 표시 방식은 없음): 수정 요청·반려 선택 시 바텀시트에서 코멘트를 입력하게 하고, 가격 설정·승인 입력도 같은 방식으로 나눈다. 근거: R4, R8
- [A13] 운영자 검수 / PRD §6-7 "자산 상세 보기": 제출된 설명·첨부 파일·사용 방법을 내 자산 상세와 같은 정보 순서로 보여주고, 체크리스트는 그 아래 또는 하단 영역으로 이어 붙인다. 근거: R1, R7
