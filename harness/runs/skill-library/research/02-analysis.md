# 분석

## 반영할 부분

- [A1] 스킬 카드 목록(PRD §6-3 필수 1): 화면 상단에 검색창, 그 아래 필터, 아래로 카드가 세로로 쌓이는 목록 구조로 구성한다. 카드에는 스킬명과 카테고리를 태그 형태로 보여준다. 근거: R1, R3
- [A2] 검색(필수 2)과 태그 필터(필수 3): 검색창 바로 아래에 가로로 넘기는 칩 줄로 태그·카테고리를 고르게 하고, 추가 조건은 드롭다운형 필터로 둔다. 근거: R1, R2, R3
- [A3] 난이도 표시(필수 7): 카드 안에 카테고리 태그와 나란히 난이도를 작은 태그로 붙여 목록에서 바로 구분되게 한다. 근거: R1, R4
- [A4] 복사 버튼(필수 4)과 파일 다운로드(필수 5): 스킬 상세 화면 하단에 고정 버튼 영역을 두고 복사·다운로드 동작을 둔다. 근거: R5
- [A5] 예시 결과 보기(필수 6)와 카드 항목(사용 순서, 주의할 점 등): 상세 화면은 탭으로 나눠 정보를 구획하고, 예시 결과를 별도 탭 또는 구역으로 둔다. 근거: R5
- [A6] 관련 미션 연결(필수 8): 상세 화면에서 관련 미션을 카드형 링크로 보여줘 미션 화면으로 이어지게 한다. 근거: R4, R5
- [A7] 검색·필터 결과가 없을 때: 빈 화면 안내 문구를 넣는다. 근거: R6
