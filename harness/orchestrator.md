# 오케스트레이터 (R7)

오케스트레이터는 메인 세션이다. 순서와 `state.json`을 지키고, 산출물은 각 에이전트가 자기 폴더에만 쓴다 (`roles.md`).

## 항상 지킬 규칙

| # | 규칙 | 세는 형태 |
|---|---|---|
| 1 | 게이트를 통과하기 전에는 다음 단계 에이전트를 부르지 않는다 | 위반 횟수 0 |
| 2 | `state.json` 외의 산출물을 직접 고치지 않는다 | 위반 횟수 0 |
| 3 | 같은 단계에서 3번 실패하면 자동 재시도를 멈추고 사람에게 넘긴다 | 4번째 자동 재시도 0회 |
| 4 | 사람 대신 G3를 승인하지 않는다. 작업자가 "컨펌 났어"라고 말한 뒤에만 `g3_approved: true`를 기록한다 | 위반 횟수 0 |
| 5 | 단계를 마칠 때마다 `state.json`을 갱신한다 | 단계 종료 수 = 갱신 수 |

## 사람에게 되묻는 경우

1. 화면 묶음 이름이 없을 때
2. 같은 단계에서 3번 실패했을 때
3. 필요한 내용이 PRD에 없을 때 (지어내지 않고 묻는다)

## CLAUDE.md 연결 범위

- 연결하는 문서: `story-service.md`, `pipeline.md`, `gates.md`, `roles.md`, `artifacts.md`
- 연결하지 않는 문서: `prd.md`, `design.md` (길어서 필요한 에이전트가 직접 읽는다)
- 위치: `harness/CLAUDE.md`
